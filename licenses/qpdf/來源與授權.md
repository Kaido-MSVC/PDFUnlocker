保留官方 sha256、sigstore 簽章資料及 API 回應；本次未執行 cosign 簽章身分驗證，雜湊比對不等於簽章驗證。

隨附 qpdf.exe、qpdf30.dll、msvcp140.dll、vcruntime140.dll、vcruntime140_1.dll，全部直接取自上述官方 ZIP。
僅取相依閉包必需檔案，沒有從 DLL 下載站或系統目錄拼湊。所有檔案均為 AMD64。
其餘 DLL 為 Windows 系統元件／UCRT。已檢查 PE 一般與延遲載入匯入，並確認實際載入的四個非系統 DLL 全部位於包內。
